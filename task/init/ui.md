# UI: Collective Unconscious Engine

## 1. Обзор и роли экранов

| # | Экран | Назначение | Маршрут |
|---|---|---|---|
| 1 | Welcome | Вход в тест, краткое описание 3 осей | `/` |
| 2 | Quiz | Прохождение теста по 3 осям (X, Y, Z) | `/quiz` |
| 3 | Result | Координаты, октант, архетип, Тень | `/result/:sessionId` |
| 4 | Space | 3D-визуализация смыслового пространства | `/space` |
| 5 | Analysis | Детальный отчёт по формату SYSTEM.md | `/analysis/:objectId` |

## 2. Дизайн-токены

```css
:root {
  --bg: #0e1116;
  --surface: #171b22;
  --border: #262c36;
  --text: #e6e9ef;
  --text-muted: #8b93a1;
  --accent: #7c5cff;
  --positive: #35d0a5;
  --negative: #ff6b6b;
  --radius: 12px;
  --font: "Inter", system-ui, sans-serif;
}
```

- Палитра тёмная, «космическая» — тема коллективного бессознательного.
- Полюса осей кодируются цветом: негативный полюс `--negative`, позитивный `--positive`.
- Анимации: `transition: 200ms ease` для смены экранов, `prefers-reduced-motion` уважается.

## 6. Экран 4 — Space (3D)

- Рендер 8 октантов как полупрозрачных параллелепипедов, оси X/Y/Z с подписями полюсов.
- Точки объектов: цвет по октанту, тултип при наведении (id, essence, координаты).
- Камера: orbit-контролы (мышь), сброс вида кнопкой.
- Выбор точки → боковая панель с архетипом и ссылкой на отчёт.

### Технический выбор
- `three.js` + `@react-three/fiber` (или чистый three.js), лёгкий fallback: SVG-изометрия при отключённом WebGL.

## 7. Экран 5 — Analysis (отчёт)

Структура повторяет формат вывода из `SYSTEM.md`:

```
1. Суть без декораций (Фактурный каркас)
2. Координаты в смысловом пространстве (X, Y, Z) — полюс + обоснование
3. Смысловой октант и Архетипический профиль
4. Проверка через «Тень»
5. Вывод
```

- Каждый блок — карточка с заголовком, текстом и иконкой.
- Кнопка «Скачать JSON» — `GET /api/v1/analysis/:id`.

## 9. Контракт с API

| Действие | Запрос | Ответ |
|---|---|---|
| Завершить тест | `POST /api/v1/quiz/{sessionId}/submit` → `{answers: [{axis, index, value}]}` | `{position: {x,y,z}}` |
| Анализ | `POST /api/v1/analysis` (`AnalyzeRequest`) | `AnalysisResponse` |
| Получить отчёт | `GET /api/v1/analysis/{objectId}` | отчёт по шаблону SYSTEM.md |
| Объекты пространства | `GET /api/v1/objects` | список точек для сцены |

## 10. Доступность и качество

- Клавиатурная навигация по карточкам ответов (`radio`-семантика, focus-visible).
- ARIA-лейблы для шкал и 3D-сцены; контраст текста ≥ 4.5:1.
- Ресайз: mobile-first, брейкпоинты `640 / 1024 / 1440`.
- Ошибки сети — retry + сохранение прогресса квиза в `sessionStorage`.
