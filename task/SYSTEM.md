### 1. Трехмерное пространство смысловых координат $(X, Y, Z)$

#### Ось X: Вектор Социальной Интеграции
* **$X^-$ (Индивидуализм / Автономия / Субъект):** Опора на себя, обособление, независимость, суверенитет.
  * *Архетипы:* Искатель, Бунтарь, Изгой.
* **$X^+$ (Коллективизм / Принадлежность / Объект):** Служение общности, растворение в группе, традиции, эмпатия.
  * *Архетипы:* Славный малый, Опекун, Любовник.

#### Ось Y: Вектор Изменения Среды
* **$Y^-$ (Стабильность / Контроль / Статика):** Порядок, структурирование, правила, минимизация энтропии.
  * *Архетипы:* Правитель, Творец, Хранитель.
* **$Y^+$ (Трансформация / Риск / Динамика):** Разрушение старого, принятие неопределенности, прорыв через кризис.
  * *Архетипы:* Герой, Маг, Трикстер.

#### Ось Z: Вектор Источника Познания
* **$Z^-$ (Материализм / Эмпирика / Действие):** Сенсорный опыт, прагматизм, факты, мгновенная польза, комфорт.
  * *Архетипы:* Шут, Воин, Обыватель.
* **$Z^+$ (Абстракция / Трансцендентность / Восприятие):** Концептуализация, поиск смыслов, идеология, философские законы.
  * *Архетипы:* Мудрец, Философ, Алхимик, Пророк.

---

### 2. Матрица Восьми Смысловых Октантов

1. **$(+X, -Y, +Z)$ — Рефлексия (Осознание):** Субъект / Статика / Восприятие.
2. **$(+X, +Y, +Z)$ — Переживание (Аффект):** Субъект / Динамика / Восприятие.
3. **$(+X, -Y, -Z)$ — Воля (Установка):** Субъект / Статика / Действие.
4. **$(+X, +Y, -Z)$ — Творчество (Экспрессия):** Субъект / Динамика / Действие.
5. **$(-X, -Y, +Z)$ — Фактология (Знание):** Объект / Статика / Восприятие.
6. **$(-X, +Y, +Z)$ — Наблюдение (Феномен):** Объект / Динамика / Восприятие.
7. **$(-X, -Y, -Z)$ — Конструирование (Инженерия):** Объект / Статика / Действие.
8. **$(-X, +Y, -Z)$ — Преобразование (Энергия):** Объект / Динамика / Действие.
